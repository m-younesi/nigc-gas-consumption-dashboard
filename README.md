# آناتومی یک زمستان — تحلیل مصرف گاز خانگی ایران، سال ۱۴۰۴

داشبورد تعاملی مصرف گاز بخش خانگی کشور به تفکیک **پلهٔ تعرفه** و **استان**،
بر پایهٔ چهار جدول منتشرشدهٔ مدیریت گازرسانی — امور تعرفه‌ها و قراردادهای
شرکت ملی گاز ایران.

## صفحه‌ها

| صفحه | توضیح |
|---|---|
| `index.html` | داشبورد اصلی: ۱۲ بخش تحلیلی و ۱۴ نمودار تعاملی |
| `poster.html` | نسخهٔ اینفوگرافیک تک‌برگ |
| `report.html` | گزارش صفحه‌بندی‌شدهٔ A4 (مبنای فایل PDF) |

## میزبانی

سایت روی دو میزبان سرو می‌شود و هر دو یک محتوا دارند:

همگام‌سازی خودکار است: هر پوش روی `main` — شامل کامیت‌هایی که پنل مدیریت
می‌زند — ورک‌فلوی [`sync-arvan.yml`](.github/workflows/sync-arvan.yml) را اجرا
می‌کند و باکت را آینه می‌کند. دخالت دستی لازم نیست.

## یافته‌های اصلی

- **۸۵٫۶٪** از مشترکین در گروه کم‌مصرف (پله‌های ۱ تا ۳) هستند، اما سهمشان از گاز
  **۶۶٫۹٪** است.
- **۳۳٫۱٪** از گاز خانگی بالاتر از سقف الگو سوخته می‌شود — توسط تنها **۱۴٫۴٪** از مشترکین.
- پرمصرف‌ترین **۱۰٪** مشترکین **۲۴٫۶٪** گاز را می‌برند؛ نیمهٔ کم‌مصرف روی هم **۲۴٫۵٪**.
- ضریب جینی مصرف در دورهٔ سرد **۰٫۳۳۳** است (کران پایین نابرابری واقعی).
- میانگین دمای استان تنها **۴۲٪** از پراکندگی مصرف مازاد بر الگو را توضیح می‌دهد؛
  مازندران و گیلان با وجود زمستان معتدل، بسیار بالاتر از انتظار اقلیمی‌شان مصرف می‌کنند.

## روش و محدودیت‌ها

ارقام مبدأ به یک رقم اعشار گرد شده‌اند و هر ردیف برای محاسبه به مجموع دقیق ۱۰۰
نرمال شده است. ضریب جینی از دادهٔ تجمیع‌شده در سطح پله محاسبه شده و نابرابری
درون هر پله را نمی‌بیند. داده «درصد» است، نه حجم مطلق. پله‌های دو نیم‌سال هم‌ارز
نیستند (۱۲ در برابر ۴)، بنابراین هیچ سهم خامی میان دو دوره مقایسه نشده است.
شرح کامل در بخش «روش‌شناسی» داشبورد آمده است.

## ساخت

فایل‌های این مخزن خروجی اسکریپت‌های پوشهٔ `build/` در مخزن مادر هستند:

```
python build/analytics.py       # dataset.json از جدول‌های خام
python build/make_map.py <geojson>   # نقشهٔ ساده‌شدهٔ استان‌ها
python build/fetch_assets.py    # تصاویر و لوگو از ویکی‌مدیا کامنز
python build/make_webdata.py    # assets/js/data.js
node   build/export_charts.js   # PNG نمودارها برای اسلایدها
python build/make_office.py     # pptx / xlsx / csv
node   build/export_pdf.js      # گزارش PDF
node   build/export_poster.js   # پوستر PNG
```
